# iGPU FilMaker

An iGPU-first, Premiere-inspired, cross-platform video editor for Windows and Linux.

> **Status: Proof of Concept (POC)** — not an MVP or production-ready editor.

The POC aims to prove that we can import media, edit a timeline, preview edits, and export a playable video on Intel and AMD integrated graphics.

**Planned stack:** Python, PySide6/Qt Quick (QML + JavaScript), and FFmpeg. Use `uv` for Python and `pnpm` only if separate JS/TS tooling becomes necessary.

See [Product Requirements](docs/PRD.md) and [POC Tasks](docs/TASKS.md).
